# Mes heures

Application personnelle de suivi du temps de travail, pensée pour être installée comme PWA sur téléphone.

## Principes

- Les pointages sont la réalité : le planning ne fabrique jamais d'heures réellement travaillées.
- Un changement de planning conserve le cumul du même emploi.
- Un changement d'emploi ouvre un nouveau compteur et archive l'ancien.
- Les données de pointage restent localement sur l'appareil dans cette version.
- L'agenda professionnel est prévu comme source de contexte, pas comme preuve automatique d'heures travaillées.

## État actuel

Prototype fonctionnel : arrivée/départ, correction des heures, pause, remarque, historique, export CSV, paramètres d'emploi, PWA/offline. L'intégration calendrier et les notifications fiables restent à implémenter et tester sur mobile.
